사용 가이드
서식 편집과 조판 전처리는 교정 탭 하단 아코디언에 통합되어 있습니다. 최종 다운로드 버튼 하나로 교정·서식·전처리를 모두 적용합니다.
기본 워크플로
  • 1hwpx_proofreader.html 파일을 더블클릭해 브라우저에서 엽니다. 설치나 서버 없이 바로 실행됩니다.
  • 2화면 상단 파일 바에 .hwpx 파일을 끌어다 놓거나 클릭해서 로드합니다. 로드된 파일은 교정·서식·전처리 모든 기능에서 공통으로 사용됩니다.
  • 3교정 탭에서 오류를 검출하고 적용할 항목을 선택합니다. 필요하면 하단 서식 편집 아코디언과 조판 전처리 아코디언도 펼쳐서 설정합니다.
  • 4맨 아래 ⬇ 최종 다운로드 버튼을 클릭하면 교정·서식·전처리가 모두 한 번에 적용된 HWPX 파일이 저장됩니다. 원본 파일은 변경되지 않습니다.
  • 5여러 파일을 한꺼번에 처리하려면 일괄처리 탭을 사용합니다.
Tip. 교정만 할 때는 서식·전처리 아코디언을 닫아 두면 됩니다. 아무것도 설정하지 않은 항목은 최종 다운로드 시 적용되지 않습니다.

규칙 관리 — 규칙 추가
  • 1교정 탭 상단 규칙 관리 아코디언 헤더를 클릭하면 규칙 관리 영역이 펼쳐집니다.
  • 2+ 새 규칙 추가 버튼을 클릭하면 규칙 편집 모달이 열립니다.
  • 3분류를 선택합니다 — 맞춤법 / 띄어쓰기 / 문장부호 / 용어 일관성 / 기타
  • 4원본에 찾을 텍스트, 수정에 바꿀 텍스트를 입력합니다. 정규식(Regex) 체크 시 원본에 JS 정규식 패턴을 쓸 수 있고, 수정 칸에서 $1, $2로 캡처 그룹을 참조합니다. 단어 경계 체크 시 단어 경계(\b)를 자동 적용합니다.
  • 5신뢰도 슬라이더로 0~100%를 설정합니다. 낮은 신뢰도 규칙은 필터로 숨길 수 있습니다. 설명란은 선택 사항입니다.
  • 6저장을 클릭하면 규칙이 즉시 저장됩니다. 브라우저를 닫아도 유지됩니다.
정규식 예시. 원본: (\d+)\s*쪽 → 수정: $1쪽 으로 설정하면 "3 쪽", "10 쪽" 등을 "3쪽", "10쪽"으로 교정합니다.
규칙 관리 — 규칙 가져오기 / 내보내기
☆ 프리셋 불러오기 — 기본 제공 규칙 세트(맞춤법, 띄어쓰기, 수험서 용어 등)를 선택해 가져옵니다. 기존 규칙에 추가됩니다.
↺ 기본 규칙으로 초기화 — 모든 규칙을 삭제하고 기본 제공 규칙으로 되돌립니다. 기존 규칙이 모두 삭제되므로 주의하세요.
↑ JSON 내보내기 / ↓ JSON 가져오기 — 규칙을 .json 파일로 저장하거나 불러옵니다. 다른 PC 이전, 팀원 공유, 백업에 활용합니다.
↑ CSV 내보내기 / ↓ CSV 가져오기 — 규칙을 엑셀에서 편집하기 편한 CSV 형식으로 저장하거나 불러옵니다.
📊 시트에서 불러오기 — Google Sheets / Excel 시트에서 복사한 탭 구분 텍스트를 붙여넣기해 규칙을 일괄 추가합니다.
⬇ 규칙 포함 HTML 내보내기 — 현재 규칙이 내장된 독립 실행 HTML 파일을 내보냅니다. 규칙을 팀원에게 파일 하나로 배포할 때 유용합니다.

오류 검출 및 결과 적용
  • 1상단에서 HWPX 파일을 로드합니다. 파일 로드 없이는 검출 버튼이 비활성화됩니다.
  • 2필요하면 옵션을 켭니다. 자모 분리 자동 검출은 'ㅎㅏㄱ' 같은 자모 분리 오류를 규칙 없이 자동으로 잡아냅니다. 조사 앞 공백 자동 검출은 '프로토콜 이라고'처럼 조사 앞에 잘못 들어간 공백을 찾습니다.
  • 3⚡ 오류 검출 시작 버튼을 클릭합니다. 파일 크기에 따라 수 초 소요될 수 있습니다.
  • 4검출 결과 목록이 표시됩니다. 상단 필터로 분류(맞춤법/띄어쓰기 등), 정렬(위치순/신뢰도순), 최소 신뢰도를 조절해 목록을 좁힐 수 있습니다.
  • 5각 항목 왼쪽 체크박스로 적용할 항목을 선택합니다. 전체 선택 / 전체 해제로 한 번에 선택할 수 있습니다.
  • 6👁 변경 미리보기로 적용 전 변경 내용을 확인할 수 있습니다.
  • 7결과 패널 아래 서식 편집 아코디언을 펼쳐 폰트·글자 크기·줄 간격 등을 설정하고, 조판 전처리 아코디언을 펼쳐 헤딩 정리·취소선 제거 등을 설정합니다. 사용하지 않을 항목은 닫아 두면 됩니다.
  • 8맨 아래 ⬇ 최종 다운로드 버튼을 클릭합니다. 선택된 교정·서식·전처리가 모두 한 번에 적용된 파일이 저장됩니다. 파일명에 적용된 작업명이 자동으로 붙습니다(예: 파일명_교정+서식.hwpx).
  • 9다운로드 후 ↩ 교정 취소(Undo) 버튼이 활성화되어 교정 적용을 되돌릴 수 있습니다. 📄 리포트 다운로드로 검출 결과를 .txt 파일로 저장할 수 있습니다.

서식 편집은 교정 탭 하단의 서식 편집 아코디언에 있습니다. 아코디언 헤더를 클릭하면 펼쳐집니다.
상단에서 HWPX 파일을 로드하면 아코디언이 활성화됩니다.
각 항목을 설정한 뒤, 교정 탭 최하단 ⬇ 최종 다운로드 버튼으로 교정·서식·전처리를 한 번에 적용합니다. 서식만 적용하고 싶을 때도 같은 버튼을 사용합니다.
체크박스로 켜야 적용되는 항목(표 설정)은 체크를 확인하세요. 비워 둔 항목은 변경되지 않습니다.
주의. 서식 편집은 HWPX 내부 XML을 직접 수정합니다. 작업 전 원본 파일을 반드시 백업하세요.
이미지 해상도 확인
파일 로드 시 HWPX 안의 모든 이미지를 자동 스캔합니다. 이름·크기·DPI가 목록에 표시됩니다.
300 DPI 미만인 이미지는 노란색 배경 + 경고 표시로 강조됩니다. 인쇄용 원고에 저해상도 이미지가 없는지 빠르게 확인할 수 있습니다.
폰트 교체
변경할 폰트(현재) 드롭다운에서 파일 안에 실제로 사용된 폰트를 선택합니다.
새 폰트(목록) 드롭다운에서 바꿀 폰트를 선택하거나, 새 폰트 직접 입력 칸에 폰트명을 직접 쓰면 드롭다운보다 우선 적용됩니다.
header.xml의 해당 폰트 참조를 전부 교체합니다. 본문·표·글상자 등 문서 전체에 일괄 적용됩니다.
글자 크기 일괄 변경
변경할 크기 선택에서 특정 글자 크기를 선택하면 해당 크기만 변경합니다. 비워두면 모든 크기를 새 크기로 교체합니다.
새 크기(pt)에 변경할 글자 크기를 입력합니다 (예: 10). 비워두면 글자 크기는 변경하지 않습니다.
줄 간격 일괄 변경
변경할 줄 간격(%)에 현재 줄 간격 값을 입력하면 그 값만 바꿉니다. 비워두면 파일 내 모든 줄 간격을 변경합니다.
새 줄 간격(%)에 바꿀 줄 간격을 입력합니다 (예: 150). 비워두면 변경하지 않습니다.
장평·자간 통일
장평(%) — 글자의 가로 비율입니다. 보통 100%가 기준이며, 90~110% 범위를 주로 사용합니다. 비워두면 변경하지 않습니다.
자간 — 글자 사이 간격입니다. 0이 기본이며 음수(좁게)·양수(넓게) 모두 입력 가능합니다. 비워두면 변경하지 않습니다.
파일 로드 후 현재 장평·자간 분포가 자동으로 표시되어 현황을 파악할 수 있습니다.
문단 여백 조정
단락(paraShape)의 위·아래·왼쪽·오른쪽 여백을 mm 단위로 설정합니다. 네 방향을 독립적으로 설정할 수 있으며, 비워두면 해당 방향 여백은 변경하지 않습니다.
표 설정
글자처럼 취급 — 표를 텍스트 흐름에 인라인 배치합니다. 표가 페이지 밖으로 밀려나는 레이아웃 문제를 방지할 때 유용합니다.
상하 여백 — 모든 표의 위·아래 여백을 mm 단위로 일괄 설정합니다. 비워두면 변경하지 않습니다.
사용 방법 공통 안내
조판 전처리는 교정 탭 하단의 조판 전처리 아코디언에 있습니다. 아코디언 헤더를 클릭하면 펼쳐집니다.
상단에서 HWPX 파일을 로드하면 아코디언이 활성화됩니다.
적용할 항목의 체크박스를 켜고, 교정 탭 최하단 ⬇ 최종 다운로드 버튼을 클릭하면 교정·서식·전처리가 한 번에 처리됩니다.
다운로드 후 아코디언 하단 로그 창에서 처리 결과를 확인할 수 있습니다.
주의. 조판 전처리는 HWPX 내부 XML 구조를 직접 수정합니다. 원본 파일을 반드시 백업하세요. 특히 헤딩 계층 정리는 기존 charPr 설정을 덮어씁니다.
① 헤딩 계층 자동 정리
단락의 텍스트 패턴(예: "1장 ", "2절 ", "①" 등)을 기준으로 헤딩 수준을 자동 판별합니다.
과목명(17pt 볼드), 장 제목(15pt 볼드), 절 제목(13pt 볼드), 소절(12pt 볼드), 항(11pt 볼드), 소항목(10.5pt) 6단계로 분류됩니다.
표 안 단락, 글상자, 빈 단락은 건드리지 않습니다.
적용 전에 🔍 헤딩 분석 (적용 전 미리보기) 버튼을 클릭하면 어떤 단락이 어떤 레벨로 분류될지 목록으로 확인할 수 있습니다. 체크박스로 특정 단락을 제외할 수도 있습니다.
헤딩 계층 정리 적용 체크박스를 켜고 최종 다운로드 버튼을 누릅니다.
Tip. 헤딩 적용 시 해당 단락의 줄간격 캐시(linesegarray)가 자동으로 초기화됩니다. 한글 재오픈 시 글자 크기에 맞게 줄 높이가 정확히 계산되므로 텍스트 겹침이 발생하지 않습니다.
② 취소선 일괄 제거
지정한 charPr ID에 설정된 취소선(strikeout)을 일괄 제거합니다. header.xml의 해당 charPr 정의에서 strikeout shape을 NONE으로 변경합니다.
대상 charPr ID 칸에 취소선을 제거할 charPr ID를 쉼표로 구분해 입력합니다 (기본값: 7,8,9,10,11,12,15,17).
취소선 제거 적용 체크박스를 켜고 최종 다운로드 버튼을 누릅니다.
여러 파일 한 번에 교정하기
  • 1교정 탭에서 교정 규칙을 먼저 설정해 두세요. 일괄처리는 저장된 규칙을 그대로 사용합니다.
  • 2일괄처리 탭의 파일 선택 영역에 여러 .hwpx 파일을 한꺼번에 끌어다 놓거나, 클릭해서 다중 선택합니다.
  • 3처리 옵션을 설정합니다. 자모 분리 자동 검출 — 규칙 없이 자모 분리 오류를 자동 감지합니다. 조사 앞 공백 자동 검출 — 조사 앞 잘못된 공백을 자동 감지합니다.
  • 4일괄 처리 시작 버튼을 클릭합니다. 파일 목록에 각 파일의 처리 상태(대기 중 → 처리 중 → 완료/오류)가 실시간으로 표시됩니다.
  • 5모든 파일 처리가 완료되면 전체 ZIP 다운로드 버튼이 활성화됩니다. 클릭하면 수정된 파일들이 하나의 ZIP으로 묶여 저장됩니다.
Tip. 파일명에 "_교정"이 자동으로 붙습니다 (예: 원고.hwpx → 원고_교정.hwpx). 원본 파일은 변경되지 않습니다.
FAQ. 규칙이 갑자기 사라졌다면 — 브라우저 사이트 데이터 초기화 또는 시크릿 모드 사용 시 localStorage가 지워집니다. JSON 내보내기로 주기적으로 백업하세요. / 검출은 됐는데 교정이 안 된다면 — 텍스트가 서식 경계로 여러 <hp:t> 요소에 쪼개진 경우입니다. 규칙을 더 짧게 조정하거나 한글에서 서식을 단순화 후 재시도하세요.
